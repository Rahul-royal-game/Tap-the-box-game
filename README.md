# 🎮 Tap The Box

Tap The Box is a fun reaction game developed by Rahul. Test your speed and accuracy by clicking the moving red box.

## Features
- 🏆 Score system
- ✅ Right click counter
- ❌ Wrong click counter
- 🖱 Total click counter
- ⏱ Stopwatch timer
- 🥇 Highest score saving
- 🎚 Easy, Medium, Hard levels
- 🔊 Sound effects
- 🎯 Random box movement
